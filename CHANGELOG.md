# Changelog

All notable changes to this project are documented in this file.

## [0.8.0] - 2026-03-22

### Added
- First public release of OpenCrystal Engine.
- Data-driven JRPG runtime covering title, overworld, events, battle, and menu loops.
- Content tooling: validation, JSON scaffolding, map editor, string scaffolding, and docs output.
- Release automation for Linux, macOS (x86_64/aarch64), and Windows binaries.

### Notes
- This release is tagged as `v0.8.0`.
